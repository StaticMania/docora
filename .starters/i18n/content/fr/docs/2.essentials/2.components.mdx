## Accordéon

::accordion
:::accordion-item{label="Qu'est-ce que Docora ?" icon="i-lucide-circle-help"}
Un framework de documentation pour Next.js : un thème, un CLI et des starters.
Le contenu est du Markdown ; le routage vient de l'arbre de fichiers.
:::

:::accordion-item{label="Où vivent les pages ?" icon="i-lucide-circle-help"}
Sous `content/{locale}/`. Créez un dossier avec `.navigation.yml` pour ajouter
une section comme celle-ci.
:::
::
