## Développement

```bash [Terminal]
npm run dev
```

Le site tourne sur `http://localhost:3000` et redirige vers la locale par défaut.

## Production

```bash [Terminal]
npm run build
npm run start
```

Chaque page de chaque locale est prérendue en HTML statique.

Voir [Configuration](/fr/docs/getting-started/configuration) pour les locales
et l'identité, puis
[Structure du projet](/fr/docs/getting-started/project-structure) pour
l'organisation des pages.
