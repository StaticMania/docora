Les documents sont du Markdown avec la
[syntaxe MDC](https://content.nuxt.com/docs/files/markdown#mdc-syntax) par-dessus,
donc les composants n'ont pas besoin d'imports.

## Encadrés

::note
Utilisez `note` pour un contexte qui n'est pas un avertissement.
::

::tip
`tip` met en avant une approche recommandée.
::

::warning
`warning` signale quelque chose qui peut mal tourner.
::

## Étapes

::steps{level="3"}

### Créer un fichier

Ajoutez `content/fr/docs/guides/1.overview.mdx`. Le `1.` fixe l'ordre.

### Nommer la section

Placez un `.navigation.yml` dans le dossier :

```yaml
title: Guides
icon: book-open
```

### Traduire

Copiez le fichier dans `content/en/docs/guides/` et traduisez le corps. Les
routes et le sélecteur de langue suivent automatiquement.

::

## Onglets et code

::tabs
:::tabs-item{label="npm" icon="i-lucide-package"}

```bash [Terminal]
npx create-docora my-docs -t i18n
```

:::

:::tabs-item{label="pnpm" icon="i-lucide-package"}

```bash [Terminal]
pnpm dlx create-docora my-docs -t i18n
```

:::

:::tabs-item{label="bun" icon="i-lucide-package"}

```bash [Terminal]
bunx create-docora my-docs -t i18n
```

:::
::

Les fences acceptent un nom de fichier. Chaque bloc a un bouton copier :

```ts [lib/source.ts]
import { createDocsSource, defaultContentDir } from 'docora'
import docsConfig from '../docs.config'

export const source = createDocsSource({
  contentDir: defaultContentDir(),
  i18n: docsConfig.i18n,
})
```
