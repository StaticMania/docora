## Development

```bash [Terminal]
npm run dev
```

The site runs at `http://localhost:3000` and redirects to the default locale.

## Production

```bash [Terminal]
npm run build
npm run start
```

Every page in every locale is prerendered as static HTML.

See [Configuration](/en/docs/getting-started/configuration) for locales and
branding, then [Project structure](/en/docs/getting-started/project-structure)
for how pages are organised.
