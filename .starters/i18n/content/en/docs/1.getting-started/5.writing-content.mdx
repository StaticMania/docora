Documents are Markdown with [MDC syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax)
on top, so components need no imports.

## Callouts

::note
Use `note` for extra context that is not a warning.
::

::tip
`tip` highlights a recommended approach.
::

::warning
`warning` flags something that can go wrong.
::

## Steps

::steps{level="3"}

### Create a file

Add `content/en/docs/guides/1.overview.mdx`. The `1.` sets sidebar order.

### Give the section a name

Put a `.navigation.yml` in the folder:

```yaml
title: Guides
icon: book-open
```

### Translate it

Copy the file into `content/fr/docs/guides/` and translate the body. Routes and
the language switcher follow automatically.

::

Fences take a filename. Every block has a copy button:

```ts [lib/source.ts]
import { createDocsSource, defaultContentDir } from 'docora'
import docsConfig from '../docs.config'

export const source = createDocsSource({
  contentDir: defaultContentDir(),
  i18n: docsConfig.i18n,
})
```
