Documents are Markdown. Headings become anchors and fill the table of contents.

## Text

| Style         | Syntax           | Output         |
| ------------- | ---------------- | -------------- |
| Bold          | `**bold**`       | **bold**       |
| Italic        | `_italic_`       | _italic_       |
| Inline code   | `` `code` ``     | `code`         |
| Link          | `[label](/en/docs)` | [label](/en/docs/getting-started/introduction) |

Press :kbd{value="Ctrl"} :kbd{value="K"} to open search.

## Lists

- [x] Task that is done

## Tables

| Convention        | Effect                        |
| ----------------- | ----------------------------- |
| `1.` prefix       | Sets sidebar order            |
| `.navigation.yml` | Sets a section title and icon |
| `navigation: false` | Hides a page from the sidebar |

::tip{to="/en/docs/essentials/components"}
MDC components sit on top of Markdown — callouts, cards, tabs and steps need
no imports. See [Components](/en/docs/essentials/components).
::
