## Writing content

Documents are markdown with [MDC](https://content.nuxt.com/docs/files/markdown#mdc-syntax)
syntax on top, so components need no imports:

::note
Callouts come in `note`, `tip`, `warning` and `caution`.
::

::card-group
:::card{title="Add a page" icon="i-lucide-file-text"}
Create an `.mdx` file under `content/` and it becomes a route.
:::

:::card{title="Add a section" icon="i-lucide-folder-tree"}
Create a folder with a `.navigation.yml` giving it a title and icon.
:::
::

## Code blocks
