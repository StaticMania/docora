## Accordion

::accordion
:::accordion-item{label="What is Docora?" icon="i-lucide-circle-help"}
A documentation framework for Next.js: a theme, a CLI and starters. Content is
Markdown; routing comes from the file tree.
:::

:::accordion-item{label="Where do pages live?" icon="i-lucide-circle-help"}
Under `content/`. Create a folder with `.navigation.yml` to add a sidebar
section like this one.
:::
::
