Welcome. This page is `content/index.mdx`, rendered with the landing layout —
header and footer, no sidebar.

[Read the docs](/docs/getting-started/introduction)

## Getting started

Everything under `content/` becomes a route. Add an `.mdx` file and it appears
in the sidebar; there are no page files to write.

## Make it yours

Edit `docs.config.ts` to change the site name, header links, socials and
footer. Drop `layout: landing` from a document's frontmatter to give it the
documentation chrome instead.
