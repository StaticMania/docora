Docora is an open-source documentation framework for Next.js and React, built with TypeScript, Tailwind CSS, and Markdown. Create fast, beautiful, SEO-friendly documentation sites with minimal configuration.

It is packaged the way Docus is for Nuxt: a **theme package**, a
**scaffolding CLI**, and **starters**.

[Read the docs](/docs/getting-started/introduction) · [Configuration](/docs/core-concepts/configuration)

## Try it

Toggle the theme in the header, then open the docs to see the sidebar and the
table of contents. Narrow the window below `1024px` and the sidebar collapses
into the drawer behind the hamburger.
