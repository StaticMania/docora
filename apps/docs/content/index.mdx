::::feature{title="File-based routing" icon="i-lucide-folder-tree" to="/docs/getting-started/project-structure"}
Every file under `content/` becomes a route. Numeric prefixes set sidebar
order and never appear in the URL.
::::

    ::::feature{title="Markdown with components" icon="i-lucide-puzzle" to="/docs/essentials/components"}
    MDC syntax puts callouts, cards, tabs and steps in your Markdown with no
    imports. JSX still works when you need it.
    ::::

    ::::feature{title="Instant search" icon="i-lucide-search" to="/docs/core-concepts/configuration"}
    A command palette over every page, built at compile time. No service to run
    and no index to host.
    ::::

    ::::feature{title="SEO by default" icon="i-lucide-globe" to="/docs/core-concepts/deployment"}
    Canonical links, sitemap, robots and generated Open Graph images, all from
    one config file.
    ::::

    ::::feature{title="Internationalisation" icon="i-lucide-languages" to="/docs/getting-started/project-structure"}
    A folder per locale. Routes, sidebar, pager, search and interface strings
    all follow, with hreflang emitted for you.
    ::::

    ::::feature{title="Built for agents" icon="i-lucide-bot" to="/docs/ai/llms-txt"}
    An `llms.txt`, raw Markdown routes, an MCP server and agent skills, so tools
    read your docs instead of scraping them.
    ::::

::section{eyebrow="Get going" title="Up and running in one command" description="Scaffold a site, start the dev server, and start writing. Node.js 20.9 or later is required."}

:::steps{level="3"}

### Create a project

The CLI detects your package manager and can scaffold a single-language or
i18n starter.

```bash [Terminal]
npx create-docora my-docs
```

### Start the dev server

```bash [Terminal]
cd my-docs && npm run dev
```

Preview the site at [http://localhost:3000](http://localhost:3000).

### Add a page

Drop an `.mdx` file into `content/` and the route and sidebar entry appear on
their own. Head to [Project structure](/docs/getting-started/project-structure)
when you want folders, prefixes and locales.

::section{eyebrow="FAQ" title="Questions, answered" description="Short answers for the things people usually ask before they scaffold."}

:::accordion

::::accordion-item{label="Do I need a CMS?" icon="i-lucide-circle-help"}
No. Pages are Markdown files. Git is the workflow, and you can still add
ordinary App Router routes next to the catch-all when a page needs custom
React.
::::

    ::::accordion-item{label="Can I add this to an existing Next.js app?" icon="i-lucide-circle-help"}
    Yes. Docora is a theme package. Install `docora`, wrap Next config with
    `withDocora`, and point it at a `content/` folder. See
    [Installation](/docs/getting-started/installation).
    ::::

    ::::accordion-item{label="How does search work?" icon="i-lucide-circle-help"}
    The index is built when the site compiles. There is no hosted search
    service and nothing extra to deploy. Open it from the header or with
    :kbd{value="Ctrl"} :kbd{value="K"}.
    ::::

    ::::accordion-item{label="Can language models read the docs?" icon="i-lucide-circle-help"}
    Yes. Every site exposes `/llms.txt`, full-corpus `/llms-full.txt`, raw
    Markdown at `/raw/{path}.md`, and an MCP server at `/mcp`.
    ::::
