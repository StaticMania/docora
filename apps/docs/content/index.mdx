Docora is an open-source Next.js framework for TypeScript, Tailwind CSS and Markdown. Routing,
search, SEO and i18n are built in. Every page also ships as an MCP server and an `llms.txt`, so
Cursor, Claude and other AI tools can read your docs directly instead of guessing.

## Why Docora

- **File-based routing** — every file under `content/` becomes a route. Numeric prefixes set
  sidebar order and never appear in the URL.
- **Built for agents** — an `llms.txt`, raw Markdown routes, an MCP server and agent skills, so
  tools read your docs instead of scraping them.
- **Markdown with components** — MDC syntax puts callouts, cards, tabs and steps in your Markdown
  with no imports.
- **Instant search** — a command palette over every page, built at compile time. No service to run,
  no index to host.
- **SEO by default** — canonical links, sitemap, robots and generated Open Graph images, all from
  one config file.
- **Internationalisation** — a folder per locale. Routes, sidebar, pager, search and interface
  strings all follow, with hreflang emitted for you.

## Built for agents

Every Docora site exposes an MCP server at `/mcp` with no extra setup. Point Cursor, VS Code or
Claude at it and the agent pulls real content from your docs instead of relying on stale training
data. `llms.txt` and `llms-full.txt` are generated automatically, and an optional AI chat widget
answers questions and cites sources on the page.

## Inspired by Docus, built for React

Docus made writing documentation genuinely enjoyable in the Nuxt ecosystem. Docora brings that same
experience — plus AI-native features like MCP and `llms.txt` — to Next.js and React. It is an
independent project with its own architecture.

## Up and running in one command

```bash [Terminal]
npx create-docora my-docs
cd my-docs && npm run dev
```

Node.js 20.9 or later is required. Drop an `.mdx` file into `content/` and the route and sidebar
entry appear on their own — see [Project structure](/docs/getting-started/project-structure).

## Questions

- **Do I need a CMS?** No. Pages are Markdown files and Git is the workflow.
- **Can I add this to an existing Next.js app?** Yes — install `docora`, wrap your Next config with
  `withDocora`, and point it at a `content/` folder.
- **How does search work?** The index is built when the site compiles; there is no hosted service.
- **Can language models read the docs?** Yes — `/llms.txt`, `/llms-full.txt`, `/raw/{path}.md` and
  an MCP server at `/mcp`.
- **Does the AI chat feature cost anything to run?** Answers go through the Vercel AI Gateway; bring
  your own API key or use the free tier. The widget is opt-in.
- **Is Docora related to Docus?** Docora is inspired by Docus but is an independent project for
  Next.js and React.
