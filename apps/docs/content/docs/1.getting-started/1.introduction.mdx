Welcome to **Docora**, an open source documentation framework built with
[Next.js](https://nextjs.org), [React](https://react.dev),
[Tailwind CSS](https://tailwindcss.com) and [MDX](https://mdxjs.com).

## What is Docora?

Docora is an open source documentation framework on top of the App Router.
The chrome — header, sidebar, table of contents, search and colour mode —
ships ready. You write Markdown with
[MDC syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) in a
`content/` folder and keep a single `docs.config.ts`.

It is built with:

::card-group
:::card{title="Next.js" icon="i-lucide-layers" to="https://nextjs.org" target="_blank"}
App Router, Server Components and a catch-all that compiles your content.
:::

:::card{title="React" icon="i-lucide-blocks" to="https://react.dev" target="_blank"}
React 19 components for layouts, search, the table of contents and MDC blocks.
:::

:::card{title="Tailwind CSS" icon="i-lucide-wind" to="https://tailwindcss.com" target="_blank"}
v4 design tokens. Recolour the site by redefining CSS variables.
:::

:::card{title="MDX" icon="i-lucide-file-code" to="https://mdxjs.com" target="_blank"}
Markdown with components. JSX still works when a page needs it.
:::
::

## Key Features

The pieces a documentation site usually has to assemble by hand:

- **Next.js 16.** App Router and Server Components — every file under `content/` is a route.
- **React 19 and TypeScript.** Published as source, with no extra build step.
- **Tailwind CSS v4.** Override semantic tokens (`--primary`, `--background`, …) in your stylesheet.
- **MDC on MDX.** Callouts, cards, tabs and steps by name — the same [MDC](https://content.nuxt.com/docs/files/markdown#mdc-syntax) syntax as Nuxt Content.
- **Auto-generated navigation.** Sidebar, pager and labels from the folder tree; numeric prefixes set order, not the URL.
- **Full-text search.** A compile-time command palette — no service or hosted index.
- **SEO by default.** Canonicals, sitemap, robots and Open Graph images from `docs.config.ts`.
- **Dark mode.** Tokens flip under `.dark` via `next-themes`.
- **Internationalisation.** A folder per locale for routes, sidebar, search and UI strings.
- **Built for agents.** `llms.txt`, raw Markdown routes, an MCP server and an in-page assistant.
