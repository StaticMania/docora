Prose components are replacements for HTML typography tags. They provide a
simple way to customize your UI when using Markdown.

Docora ships a set of styled prose components so you can write documentation
with [MDC syntax](https://content.nuxt.com/docs/files/markdown#mdc-syntax) —
no imports. Every example below has a live preview and the source to copy.

## Accordion

Use the `accordion` and `accordion-item` components to display a collapsible
list of questions and answers.

::code-preview

:::accordion

::::accordion-item{label="What is Docora?" icon="i-lucide-circle-help"}

starters. Content is markdown, routing comes from the file tree.
::::

::::accordion-item{label="What do I need to start?" icon="i-lucide-circle-help"}
A `content/` folder. Everything else has a default.
::::

::::accordion-item{label="Can I use React components?" icon="i-lucide-circle-help"}
Yes — documents are MDX, so JSX works alongside MDC syntax.
::::

:::

## Callout

Use markdown in the default slot of the `callout` component to add
eye-catching context to your content.

Use the `icon` and `color` props to customize it. You can also pass `to` to
turn the whole callout into a link.

You can also use the `note`, `tip`, `warning` and `caution` shortcuts with
pre-defined icons and colours.

::code-preview

:::note
Here's some additional information for you.
:::

:::tip
Here's a helpful suggestion.
:::

:::warning
Be careful with this action as it might have unexpected results.
:::

:::caution
This action cannot be undone.
:::

#code
```mdc
::note
Here's some additional information for you.
::

::tip
Here's a helpful suggestion.
::

::warning
Be careful with this action as it might have unexpected results.
::

::caution
This action cannot be undone.
::
```

## Card and CardGroup

Use markdown in the default slot of the `card` component to highlight your
content.

Use the `title`, `icon` and `color` props to customize it. You can also pass
`to` to turn the card into a link.

Wrap your `card` components with the `card-group` component to group them
together in a grid layout.

::code-preview

:::card-group

::::card{title="Installation" icon="i-lucide-download" to="/docs/getting-started/installation"}
Wire the theme into a Next.js app.
::::

::::card{title="Project Structure" icon="i-lucide-folder-tree" to="/docs/getting-started/project-structure"}
How content maps onto routes.
::::

::::card{title="Configuration" icon="i-lucide-settings" to="/docs/core-concepts/configuration"}
Every option the theme reads.
::::

::::card{title="Code Blocks" icon="i-lucide-code" to="/docs/essentials/code-blocks"}
Filenames, highlighting and groups.
::::

:::

## Field and FieldGroup

A `field` is a prop or parameter to display in your content. Group them with
`field-group` in a list.

::code-preview

:::field-group

::::field{name="site.name" type="string" required}
The site name, used as the header title fallback.
::::

::::field{name="header.search" type="boolean"}
Set to `false` to remove the search trigger. Defaults to `true`.
::::

::::field{name="colorMode.forced" type="'light' | 'dark'"}
Pins the site to one colour mode and hides the toggle.
::::

::::field{name="site.url" type="string"}
Canonical site URL. Enables the sitemap, social images and edit links.
::::

:::

#code
```mdc
::field-group
  :::field{name="site.name" type="string" required}
  The site name, used as the header title fallback.
  :::

  :::field{name="header.search" type="boolean"}
  Set to `false` to remove the search trigger. Defaults to `true`.
  :::

  :::field{name="colorMode.forced" type="'light' | 'dark'"}
  Pins the site to one colour mode and hides the toggle.
  :::

  :::field{name="site.url" type="string"}
  Canonical site URL. Enables the sitemap, social images and edit links.
  :::
::
```

## Steps

Wrap your headings with the `steps` component to display a list of steps.

Use the `level` prop to define which heading will be used for the steps.

::code-preview

:::steps{level="4"}

#### Create your docs directory

```bash [Terminal]
npx create-docora my-docs
```

#### Start the development server

```bash [Terminal]
cd my-docs
npm run dev
```

:::
