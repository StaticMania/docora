Prose components replace HTML typography tags and are available in every
document by name — no imports. Write them with MDC syntax.

## Accordion

::accordion

  :::accordion-item{label="What is next-docs?" icon="i-lucide-circle-help"}
  A documentation framework for Next.js: a theme package, a scaffolding CLI and
  starters. Content is markdown, routing comes from the file tree.
  :::

  :::accordion-item{label="What do I need to start?" icon="i-lucide-circle-help"}
  A `content/` folder. Everything else has a default.
  :::

  :::accordion-item{label="Can I use React components?" icon="i-lucide-circle-help"}
  Yes — documents are MDX, so JSX works alongside MDC syntax.
  :::

::

## Callout

Use `note`, `tip`, `warning` and `caution` for pre-set icons and colours, or
`callout` with your own `icon`, `color` and `to`.

::note
Here's some additional information for you.
::

::tip
Here's a helpful suggestion.
::

::warning
Be careful with this action as it might have unexpected results.
::

::caution
This action cannot be undone.
::

::callout{icon="i-lucide-rocket" to="/docs/getting-started/installation"}
A callout with `to` becomes a link to another page.
::

## Field and FieldGroup

::field-group

  :::field{name="site.name" type="string" required}
  The site name, used as the header title fallback.
  :::

  :::field{name="header.search" type="boolean"}
  Set to `false` to remove the search trigger. Defaults to `true`.
  :::

  :::field{name="colorMode.forced" type="'light' | 'dark'"}
  Pins the site to one mode and hides the toggle.
  :::

## Steps

::steps{level="3"}

### Install the theme

```bash [Terminal]
npm install docs-theme
```

### Add a content file

Create `content/index.mdx` with frontmatter and a body.

### Run the dev server

```bash [Terminal]
npm run dev
```
