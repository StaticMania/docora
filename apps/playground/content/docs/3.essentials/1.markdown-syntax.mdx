Documents are MDX, so components can be used by name without importing
anything.

## Callouts

<Note>
The default callout, for information worth setting apart from the body text.
</Note>

<Tip title="Worth knowing">
Every callout takes an optional `title`.
</Tip>

<Warning>
Something that will cause trouble if it is overlooked.
</Warning>

<Caution>
Something destructive or irreversible.
</Caution>

Write them as `<Note>`, `<Tip>`, `<Warning>` and `<Caution>`, or use
`<Callout type="warning">` directly.

## Code blocks

Fenced code is highlighted by Shiki at compile time, with both colour schemes
emitted as custom properties so switching themes needs no re-render:

```ts
import { createDocsSource, defaultContentDir } from 'docs-theme'

export const source = createDocsSource({ contentDir: defaultContentDir() })

const page = await source.getPage(['docs', 'getting-started', 'installation'])
```

```css
:root {
  --primary: var(--color-emerald-500);
}
```

Inline `code` is styled separately from blocks.

## Tables and quotes

| Convention          | Effect                          |
| ------------------- | ------------------------------- |
| `1.` prefix          | Sets sidebar order              |
| `.navigation.yml`    | Sets a section title and icon   |
| `navigation: false`  | Hides a page from the sidebar   |

> GitHub-flavoured markdown is enabled, so tables, strikethrough and task
> lists all work.
