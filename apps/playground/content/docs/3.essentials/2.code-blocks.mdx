## Basic

### Inline Code

Use inline code to reference a symbol inside a sentence, like `defineDocsConfig`.

### Code Blocks

Fenced code is highlighted at build time by Shiki, with a copy button on hover:

```ts
export default defineDocsConfig({
  site: { name: 'Acme' },
})
```

Add a filename in brackets and it appears in a header, with an icon chosen from
the extension:

```ts [docs.config.ts]
import { defineDocsConfig } from 'docs-theme'

export default defineDocsConfig({
  site: { name: 'Acme' },
})
```

### Highlighting lines

Append line numbers in braces to draw attention to part of a snippet:

```ts [next.config.ts]{3-5}
import { withDocsTheme } from 'docs-theme/next'

export default withDocsTheme({
  contentDir: 'content',
})
```

Add `line-numbers` to number every line:

```css [app/globals.css] line-numbers
@import "tailwindcss";
@import "docs-theme/styles.css";
```

## Advanced

### CodeGroup

Group related snippets into tabs — ideal for package managers:

::code-group

```bash [npm]
npm install docs-theme
```

```bash [pnpm]
pnpm add docs-theme
```

```bash [yarn]
yarn add docs-theme
```

::

### CodeTree

Show a set of files together with a tree beside them:

::code-tree{default-value="docs.config.ts"}

```ts [next.config.ts]
import { withDocsTheme } from 'docs-theme/next'

export default withDocsTheme({})
```

```ts [docs.config.ts]
import { defineDocsConfig } from 'docs-theme'

export default defineDocsConfig({
  site: { name: 'Acme' },
})
```

```css [app/globals.css]
@import "tailwindcss";
@import "docs-theme/styles.css";
```

::

### CodeCollapse

Collapse a long file behind a toggle:

::code-collapse

```css [app/globals.css]
@import "tailwindcss";
@import "docs-theme/styles.css";

:root {
  --primary: var(--color-blue-500);
  --radius: 0.5rem;
}

.dark {
  --primary: var(--color-blue-400);
}

body {
  font-feature-settings: "cv02", "cv03";
}
```

::
