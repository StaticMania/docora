A documentation framework for Next.js, packaged the way Docus is packaged for
Nuxt: a **theme package**, a **scaffolding CLI**, and **starters**. This page
uses the landing layout — header and footer, no asides.

[Read the docs](/docs) · [Configuration](/docs/configuration)

## Try it

Toggle the theme in the header, then open the docs to see the sidebar and the
table of contents. Narrow the window below `1024px` and the sidebar collapses
into the drawer behind the hamburger.
